# APASU App

Aplicació oficial de l'Associació de Pares d'Autisme de Sueca (APASU).

## Funcions previstes

- Gestió de socis
- Activitats i inscripcions
- Rebuts i quotes
- Pagaments (Bizum, transferència i efectiu)
- Comunicats
- Finances
- Control d'assistència
- Notificacions
- Valencià / Castellà
- Android i iPhone
